# Mandelbrot Zoomer

A high-performance, deep-precision Mandelbrot zoomer for the browser.

## Direction

- WebGPU-first rendering
- XaoS-like continuous zooming
- Adaptive internal resolution and temporal reprojection
- Progressive precision tiers, including perturbation-based deep zoom
- WebGL2 fallback where practical
- Static deployment through GitHub Pages

The project is currently being bootstrapped.
